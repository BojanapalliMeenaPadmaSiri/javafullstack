# Movie Watchlist – Java Full Stack Application

A full-stack Movie Watchlist application developed using **Spring Boot**, **React**, and **MySQL**. The application enables users to perform CRUD operations on movie records through RESTful APIs and a responsive user interface.

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- React (Vite)
- HTML, CSS, JavaScript
- Axios
- Maven
- Jenkins
- Git & GitHub

## Features

- Add, View, Update, and Delete Movies
- RESTful API Integration
- MySQL Database Connectivity
- Responsive React Frontend
- Jenkins CI/CD Pipeline

## Setup

### Backend

```bash
mvn clean install
mvn spring-boot:run
```

### Frontend

```bash
npm install
npm run dev
```

### Database

Create a MySQL database named:

```sql
CREATE DATABASE fullstackdb1;
```

Update `application.properties` with your database credentials.
